# North Star Bakery

This is my multi-page website project for North Star Bakery (Client A) for Introduction to Web Development.

## Files Included
- index.html - Home page with welcome section, weekly featured brioche loaf, and store hours.
- products.html - Breads, morning pastries, and custom cakes with prices.
- about.html - Bakery story, local farm sourcing, staff list, and kitchen video.
- contact.html - Location info and pre-order request form.
- styles.css - Stylesheet with Flexbox layout and media query for larger screens.

## How to View
Open index.html in any web browser, or visit the live GitHub Pages site at https://dronesmiths.github.io/north-star-bakery/
